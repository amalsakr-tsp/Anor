# Anor

This repository contains the Python code associated with the published paper:

**Co-investment under Revenue Uncertainty Based on Stochastic Coalitional Game Theory**  
Amal Sakr, Andrea Araldo, Tijani Chahed, and Daniel Kofman.

Published in **Annals of Operations Research**, 2026.

**Paper:** [Paper link](https://doi.org/10.1007/s10479-026-07222-w)

## Overview

The code implements the stochastic coalitional game studied in the paper. An Infrastructure Provider (InP) and multiple Service Providers (SPs) jointly invest in Mobile Edge Computing (MEC) infrastructure under uncertain future revenues.

The framework jointly determines the infrastructure capacity and the dynamic allocation of computational resources among the participating SPs. Coalition values are evaluated based on the revenues generated by the SPs and the infrastructure deployment and maintenance costs.

The implementation also computes coalition payoff allocations and evaluates the stability and profitability of the grand coalition under revenue uncertainty.

## Main files

* `mainstochastic.py`: runs the stochastic co-investment analysis and coordinates the main numerical experiments under revenue uncertainty.
* `main.py`: constructs the feasible coalitions and evaluates their coalition values, infrastructure capacities, resource allocations, and player payoffs.
* `game.py`: implements the coalitional game, evaluates coalition payoffs, and computes player-level revenue and payment allocations.
* `gamestochastic.py`: implements the stochastic coalitional-game analysis, including coalition excesses, stability measures, stochastic revenue deviations, and probability calculations.
* `optimizationconvex.py`: implements the stochastic traffic model, including fractional Brownian motion-based load fluctuations, and the corresponding resource-allocation optimization.
* `kkt.py`: implements the KKT-based resource-allocation and infrastructure-capacity optimization used to determine the optimal coalition investment.
* `utils.py`: generates the feasible coalitions considered in the coalitional-game evaluation.

## Requirements

The code requires Python 3.10 or later. The main dependencies include `numpy`, `scipy`, `cvxpy`, `matplotlib`, and `fbm`, which are specified in `requirements.txt`.

To install the dependencies, run:

```bash
pip install -r requirements.txt
```

## Running the experiments

To run the main stochastic numerical experiment:

```bash
python mainstochastic.py
```

The script evaluates the co-investment model under revenue uncertainty and generates the numerical results used in the paper.

The main parameters, including the uncertainty level, Hurst parameter, investment period, traffic characteristics, infrastructure costs, and number of players, can be modified in the corresponding Python files.

## Outputs

The code produces numerical results including coalition values, optimal infrastructure capacity, dynamic resource allocations, individual player payoffs, revenues and payments, coalition excesses, stability measures, and probabilistic evaluations of the co-investment under revenue uncertainty.
